# DET-001 Validation Evidence

## Detection

**DET-001:** Suspicious Child Process Spawned by Windows FTP Client

## Dataset

- Dataset ID: DS-001
- Source: EVTX-ATTACK-SAMPLES
- Sample: `Execution/exec_sysmon_1_ftp.evtx`
- Provider: Microsoft-Windows-Sysmon
- Event ID: 1 - Process Creation

## Detection Hypothesis

A command or scripting interpreter spawned directly by the Windows FTP
client represents an unusual process relationship that warrants
investigation.

## Observed Evidence

The selected EVTX contains four Sysmon process-creation records.

The relevant record contains:

- Image: `C:\Windows\System32\cmd.exe`
- ParentImage: `C:\Windows\System32\ftp.exe`
- CommandLine: `C:\Windows\system32\cmd.exe /C c:\Windows\system32\calc.exe`
- User: `IEWIN7\IEUser`
- UtcTime: `2019-05-12 17:20:49.261`

The subsequent process-creation record contains:

- Image: `C:\Windows\System32\calc.exe`
- ParentImage: `C:\Windows\System32\cmd.exe`

Observed process chain:

`ftp.exe -> cmd.exe -> calc.exe`

## ATT&CK Mapping

**T1059.003 - Command and Scripting Interpreter: Windows Command Shell**

Rationale: the validated event records execution of `cmd.exe` as part of
the observed process chain.

## Severity

**Medium**

The parent-child relationship is unusual and investigation-worthy, but
the relationship alone does not establish malicious impact.

## False Positives

Potential false positives include legitimate administrative or legacy
automation that intentionally launches a command or script interpreter
from the Windows FTP client.
