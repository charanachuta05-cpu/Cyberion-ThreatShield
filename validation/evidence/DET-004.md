## Detection

**Kerberos Password Spray Indicators Across Multiple Accounts**

- Dataset ID: DS-004

## Detection Hypothesis

Repeated Kerberos authentication failures involving multiple distinct
accounts from a common source can provide evidence consistent with
password-spraying behavior.

- Event ID 4768 with Status `0x00000006`

- Authentication infrastructure problems

## Analyst Interpretation

The rule identifies behavior consistent with password spraying. A match
is not, by itself, proof of malicious activity and must be evaluated
with host, user, network, and authentication context.
